# Komorebi Bank — 2026-10-10

こもれび銀行 is available from level 1 on the village map and through the plaza. Players enter a full-screen bank scene, walk to an animated squirrel teller, and open a bank book. A visiting villager may appear and responds with bank-specific dialogue. `/bank` opens the same scene; `/bank-mobile.html` embeds the real app at 390 × 800 for layout review.

## Game rules

One outcome per elapsed calendar day, starting the day after deposit:

- Normal (92%): 1% interest.
- Good economy (3%): 2% interest.
- Robbery (4%): lose 10% of deposited points, rounded upward; no interest that day.
- Bankruptcy (1%): return 75% of deposits, rounded downward, to the wallet; lose the rest; close for the event day and reopen the next day.

Only fictional YOKI points are involved. The wallet is never robbed. Terms and daily probabilities appear before submitting a deposit. Deposits/withdrawals have no fee, accept whole points, and have a 1,000,000 point account limit. Fractional interest carries forward. History retains 80 entries; lifetime interest/loss totals persist.

## Persistence

Bank state is nested in the existing FeedState cloud snapshot. Wallet, principal, fractional carry, day receipts and transaction identity are committed in one recoverable storage transaction. A persisted seed and calendar date determine events so reopening cannot reroll. Offline catch-up produces the same results as visiting daily. Stale revisions and command IDs prevent double spending/retry duplication. Settlement is committed even when a requested trade is no longer valid because bankruptcy occurred. Corrupted records and backward dates are rejected without resetting balances.

Local AppContext uses its existing privateCache owner guard. Replit retains its existing auth/cloud-sync guard and bowlingOwner scope check; only the bank callback and type/provider additions were patched into that file. Existing authentication code was preserved.

## Art and performance

The built-in image generation tool produced two new original assets: an elevated-view warm wood bank with purple counter runners, brass vault and clear foreground; and an isolated soft furry squirrel teller with brass glasses, plum waistcoat and ledger, no scarf. Existing village-homewares art guided the backdrop style. Exported with Pillow resize/encoding only: web uses village-bank.webp (about 174 KiB) and bank-teller.webp (about 78 KiB); native uses JPG/PNG fallbacks. The backdrop and teller are preloaded together only when entering this scene. No new dependencies or per-frame bank logic.
