# 日本語の見直し（2026-11-05）

バトル画面の「事実と予想を分ける」だけでは、何をすればよいのか伝わりにくかった。共通の抽象的な選択肢を場面ごとに書き分け、問題文と選択後の説明もつながるように修正した。

## 確認範囲

- モヤモヤバトル全6種類：12場面、30種類の選択肢と説明、遭遇・勝敗・参加日数・ルールの案内。
- 記録入力、ホーム、日記、記録の推移、ヒント帳、月次レポート、主なメニュー・設定・使い方の固定文言。
- ショップ、着ぐるみ、進化、模様替え、プロフィール、ログイン、ゆでたまごの表示文言も確認。
- AIがその都度生成する返事、保存済みの日記本文は今回の固定文言確認には含めない。

## 主な修正例

| 修正前 | 修正後 |
| --- | --- |
| 「嫌われたのかな」が気になっている。 | 送ったメッセージへの返事が短くて、「嫌われたのかな」と不安になった。 |
| 事実と予想を分ける | 「返事が短い＝嫌われた」とは決めつけない |
| 最初の5分に分ける | 5分でできる小さな作業から始める |
| 残った荷物をどう扱おう？ | まだ作業がいくつも残っている。無理なく進めるには、どうする？ |
| 急な言い方にイライラ。 | 相手にきつい言い方をされて、イライラしている。 |
| 選ぶヒントを試すミニゲームです。 | 身近な場面を例に、モヤモヤへの対処法を選ぶゲームです。 |
| 向き合った日 | バトルに参加した日 |
| 続けて残した日 | 最長の連続記録 |
| 今日のことを分けてくれて、ありがとう。 | 今日のことを聞かせてくれて、ありがとう。 |
| いちばん前の日記 | はじめて書いた日記 |

ほかに、敵のHPを0にすれば勝ちであること、参加日数は連続でなく合計であること、記録のお知らせが表示される条件を具体的に説明した。場面は例であることもバトル画面に表示する。
