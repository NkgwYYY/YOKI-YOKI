---
name: Internal item administration
description: Where YOKI YOKI operators manage shop inventory without exposing administration inside the consumer app.
---

Item administration must live in a separate Replit-only web artifact. Do not add an admin route, button, or menu entry to the consumer mobile app.

**Why:** The owner explicitly wants operational controls available from the Replit workspace rather than visible or discoverable by app users.

**How to apply:** Future catalog, pricing, asset, and availability controls should extend the internal management artifact. The mobile app should expose only the user-facing shop.
