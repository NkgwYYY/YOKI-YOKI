重要な修正です。

現在のキャラクターアニメーションで、笑顔（喜・楽など）にしたときに
キャラクター本体や頬の形が変形しています。

また、頬の端が四角く欠ける問題もまだ残っています。

今回は「頬を最前面にする」だけではなく、
【表情アニメーションによって頬や本体の形そのものを変形させない】
ことを最優先にして修正してください。

━━━━━━━━━━━━━━━━━━
【最重要：元画像の形を絶対に変えない】
━━━━━━━━━━━━━━━━━━

表情を変えても、

・キャラクター本体の輪郭
・毛並み
・頬の形
・頬のサイズ
・頬の縦横比
・目の基本形状
・口の基本形状

を勝手に引き伸ばしたり、潰したり、歪ませたりしないでください。

特に「喜」「楽」の表情にした際に、
キャラクター全体が横に伸びたり、
頬が横長・縦長になったりする現在の挙動を禁止してください。

━━━━━━━━━━━━━━━━━━
【重要：表情と身体変形を分離】
━━━━━━━━━━━━━━━━━━

現在の実装で、

emotion → parent transform → 子要素全部が変形

という構造になっていないか確認してください。

例えば、

.character {
  transform: scale(...);
}

のような処理を表情変更に使っている場合、
そのtransformによって、

BODY
EYE
MOUTH
CHEEK

全部が同時に変形してしまいます。

これはやめてください。

「喜」「楽」などの表情変更では、
基本的に顔パーツの形状を直接変形させないでください。

━━━━━━━━━━━━━━━━━━
【頬は完全に独立】
━━━━━━━━━━━━━━━━━━

CHEEKは独立したレイヤーにしてください。

構造は、

character
├── body-layer
├── eye-layer
├── mouth-layer
└── cheek-layer

としてください。

cheek-layerは他のパーツのtransformの影響を受けないようにしてください。

特に、

scaleX
scaleY
rotate
skew
translate

を、表情変更のためにcheek-layerへ適用しないでください。

━━━━━━━━━━━━━━━━━━
【頬の形状固定】
━━━━━━━━━━━━━━━━━━

頬は元画像の形をそのまま維持してください。

例えば元画像の頬が楕円形なら、

喜：
楕円形のまま

怒：
楕円形のまま

哀：
楕円形のまま

楽：
楕円形のまま

驚：
楕円形のまま

にしてください。

感情によって頬そのものを
横に伸ばしたり、縦に潰したりしないでください。

感情表現は、

・位置
・透明度
・色の強さ
・微小な移動

などで表現してください。

━━━━━━━━━━━━━━━━━━
【笑顔時の変形を禁止】
━━━━━━━━━━━━━━━━━━

特に「喜」「楽」で、

scaleX > 1
scaleY < 1

などによってキャラクターを横長にする処理があれば削除してください。

また、

border-radius
clip-path
SVG transform
Canvas transform
CSS transform

によって顔や頬の形状を変えていないか確認してください。

━━━━━━━━━━━━━━━━━━
【身体の動きは別レイヤー】
━━━━━━━━━━━━━━━━━━

「ジャンプ」「呼吸」「ブルブル」などで身体を動かす必要がありますが、

身体全体の動きと表情を完全に分離してください。

例えば、

BODY_ANIMATION

と

FACE_ANIMATION

を別々に管理してください。

BODY_ANIMATIONでは、

translateY
translateX
rotate

などを使用して構いません。

ただし、表情変更だけではBODYを変形させないでください。

また、身体を上下に動かす場合でも、
可能な限りscaleによる変形ではなくposition移動を優先してください。

━━━━━━━━━━━━━━━━━━
【ボーンについて】
━━━━━━━━━━━━━━━━━━

現在導入したボーンシステムがある場合も、

CHEEK
EYE
MOUTH

に対して親BODYのscaleを継承させない構造にしてください。

例えば、

Root
└── Body
    └── Face

のBodyにscaleを掛けると、
Face以下の全部が変形します。

そのため、

Root
├── Body
└── Face
    ├── Eye
    ├── Mouth
    └── Cheek

のように、
顔パーツを必要に応じてBody変形から独立させてください。

ただし、画面上では正しくBodyに追従する必要があります。

つまり、

位置はBodyに追従
形状は変形しない

という状態にしてください。

━━━━━━━━━━━━━━━━━━
【頬の四角い欠けも同時に修正】
━━━━━━━━━━━━━━━━━━

現在残っている頬の四角い欠けについても、
同時に根本修正してください。

CHEEKは、

・clip-path: none
・mask: none
・mask-image: none
・overflow: visible

を基本としてください。

親要素にも頬を切断するclip / mask / overflow hiddenがないことを確認してください。

また、頬PNG自体に四角い背景が残っていないか確認してください。

頬の外側は完全透明（alpha=0）でなければいけません。

━━━━━━━━━━━━━━━━━━
【描画順】
━━━━━━━━━━━━━━━━━━

必ず、

BODY
↓
EYE
↓
MOUTH
↓
CHEEK

の順番で描画してください。

CHEEKは最後です。

ただし、
「最後に描画する」ことと
「変形させる」ことは別問題です。

CHEEKを最前面にしても、
CHEEK自体の形状を変形させないでください。

━━━━━━━━━━━━━━━━━━
【表情の作り方を変更】
━━━━━━━━━━━━━━━━━━

表情を「キャラクター全体の画像変形」で作らないでください。

基本方針は、

通常
↓
顔パーツの状態変更
↓
必要なら小さな位置変化
↓
表情完成

です。

例えば「喜」なら、

・目 → 少し閉じる
・口 → 元画像に忠実な笑顔形状
・頬 → 位置と透明度を少し変える
・身体 → 基本形状を維持

としてください。

キャラクター全体を横に伸ばして
「笑っているように見せる」方法は禁止です。

━━━━━━━━━━━━━━━━━━
【重要：AI再生成について】
━━━━━━━━━━━━━━━━━━

表情素材をAIで再生成する場合も、
元画像のキャラクター形状を維持してください。

AI生成画像を、

character全体の新しい画像

として表示して変形させるのではなく、

必要な顔パーツだけを表情素材として扱ってください。

特に頬については、
可能なら元画像の頬素材をそのまま使用してください。

━━━━━━━━━━━━━━━━━━
【デバッグ】
━━━━━━━━━━━━━━━━━━

まず「喜」を選択したときに、
どのCSS / JS / Canvas処理が

scale
scaleX
scaleY
rotate
skew
transform

を変更しているかログを出してください。

例えば、

[EMOTION DEBUG]

のように確認できるようにしてください。

「喜」に変更した瞬間に
どの要素のscaleが変わっているか特定してください。

原因を特定したうえで修正してください。

━━━━━━━━━━━━━━━━━━
【最終的な完成状態】
━━━━━━━━━━━━━━━━━━

「喜」「楽」にしても、

・キャラクター本体の輪郭は変わらない
・頬の形は変わらない
・頬の端は欠けない
・頬が四角く切れない
・顔全体が横長にならない
・顔全体が縦に潰れない
・目や口が不自然に引き伸ばされない

状態にしてください。

そのうえで、

・目
・口
・頬
・目線
・小さな位置変化

を組み合わせて、
「ちゃんと笑っている」と分かる表情を作ってください。

最重要なのは、

【感情を変えてもキャラクターの形状そのものは変えない】

ことです。

まず現在のコードを調査し、
喜・楽を選択した際に発生している
scale / transform / clip / mask の原因を特定してから修正してください。
